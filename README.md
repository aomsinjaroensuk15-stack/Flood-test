# เช็กน้ำท่วม

เว็บแอปบนมือถือ (PWA) ที่ช่วยประเมิน **ความเสี่ยงน้ำท่วมเบื้องต้น** ของจุดที่คุณอยู่ หรือจุดอื่นที่เลือกบนแผนที่ จากข้อมูลฝนและปริมาณน้ำในแม่น้ำที่โมเดลจำลอง

### [กดที่นี่เพื่อเปิด](https://aomsinjaroensuk15-stack.github.io/Flood-test/)

> ⚠️ **ข้อสำคัญ:** แอปนี้เป็นการประเมินความเสี่ยงเบื้องต้นจากข้อมูลสาธารณะ **ไม่ใช่คำเตือนภัยทางการ** และไม่รับประกันว่าพื้นที่ใดปลอดภัยหรือจะไม่ท่วม หากอยู่ในสถานการณ์อันตราย ให้ทำตามประกาศและคำสั่งของเจ้าหน้าที่ก่อนเสมอ

## ทำอะไรได้บ้าง

- **ใช้ตำแหน่งของฉัน** ขอสิทธิ์ GPS ของเบราว์เซอร์เพื่อเช็กจุดที่คุณอยู่ หรือ **แตะบนแผนที่** เพื่อเลือกจุดอื่น
- **ระดับความเสี่ยง 4 ระดับ:** ไม่พบสัญญาณเสี่ยง / เฝ้าระวัง / เสี่ยง / อันตราย พร้อมเหตุผลสั้นๆ
- **ฝนสะสมย้อนหลัง 24 ชม.** และ **ฝนพยากรณ์ 48 ชม.** ข้างหน้า
- **พยากรณ์ฝน 7 วัน** แสดงเป็นกราฟแท่งรายวัน
- **ช่วงเวลาเสี่ยงที่คาด** ประมาณช่วงวันที่ฝนหนักและน้ำในแม่น้ำ (จำลอง) น่าจะสูงสุดใน 7 วันข้างหน้า พร้อมช่วงเวลาที่ฝนหนักสุดใน 6 ชม. (เป็นการประมาณ ไม่ใช่การทำนายเวลาน้ำท่วมจริง)
- **ปริมาณน้ำในแม่น้ำ (จำลอง)** ค่าวันนี้ ยอดสูงสุดใน 7 วัน และเทียบกับค่าสูงสุดย้อนหลัง 90 วัน
- **บันทึกจุด** ตั้งชื่อ เช่น "บ้าน" แล้วกดเช็กซ้ำได้เร็ว (สูงสุด 6 จุด)
- **แสดงความอันตราย** ปุ่มลงสีบนแผนที่ตามระดับ เฝ้าระวัง (เหลือง) / เสี่ยง (ส้ม) / อันตราย (แดง) จากจุดตัวอย่าง 7×7 ช่องในกรอบแผนที่ที่เห็น แตะช่องสีเพื่อดูเหตุผล
- **ภาพรวมทุกจุดที่บันทึก** เห็นระดับความเสี่ยงของบ้าน ที่ทำงาน และจุดอื่นๆ ในหน้าเดียว กดเพื่อดูรายละเอียด
- **ความสูงพื้นที่โดยประมาณ** จากแบบจำลองภูมิประเทศ Copernicus DEM (ความละเอียด ~90 ม.)
- **สถานที่ฉุกเฉินใกล้ฉัน** โรงพยาบาล สถานีตำรวจ และดับเพลิงในรัศมี 8 กม. พร้อมระยะทางและลิงก์นำทาง
- **แชร์ผล** ส่งข้อความสรุปผ่านเมนูแชร์ของมือถือ
- **เช็กลิสต์เตรียมตัวรับน้ำท่วม** และปุ่มโทรขอความช่วยเหลือ (ปภ. 1784, การแพทย์ฉุกเฉิน 1669)
- **ติดตั้งเป็นแอปได้** (เพิ่มลงหน้าจอหลัก) และเปิดดูผลล่าสุดที่เก็บไว้ได้เมื่อเน็ตหลุด

## ใช้งานอย่างไร

1. เปิดแอป แล้วกด **ใช้ตำแหน่งของฉัน** (หรือแตะแผนที่)
2. ดูการ์ดสรุประดับความเสี่ยง กราฟฝน 7 วัน และรายละเอียดด้านล่าง
3. กด **บันทึกจุดนี้** หากต้องการกลับมาเช็กจุดเดิมบ่อยๆ

ตำแหน่งและจุดที่บันทึกเก็บไว้ **ในเครื่องของคุณเท่านั้น** (localStorage) แต่พิกัดของจุดที่เลือกจะถูกส่งไปยัง Open-Meteo เพื่อขอข้อมูลฝนและแม่น้ำ

## ประเมินความเสี่ยงอย่างไร

แอปใช้กฎง่ายๆ (rule-based) ไม่ได้ใช้โมเดล machine learning:

| ปัจจัย | ผลต่อระดับ |
|---|---|
| ฝน 24 ชม. / 48 ชม. / รายวันใน 7 วัน เกินเกณฑ์ | เฝ้าระวัง หรือ เสี่ยง |
| ปริมาณน้ำในแม่น้ำ (จำลอง) ใกล้หรือสูงกว่าค่าสูงสุดรอบ 90 วัน | เฝ้าระวัง หรือ เสี่ยง |
| ทั้งฝนหนักมากและน้ำในแม่น้ำสูงกว่าช่วง 90 วัน | อันตราย |
| ข้อมูลเก่าเกิน 3 ชม. หรือไม่มีข้อมูล | **ข้อมูลไม่พอ** (ไม่แสดงว่าปลอดภัย) |

> เกณฑ์ตัวเลขทั้งหมดเป็น **ค่าตั้งต้น (placeholder)** ที่ยังไม่ได้เทียบกับเกณฑ์ทางการหรือเหตุการณ์จริง ปรับได้ที่ค่าคงที่ `T` และฟังก์ชัน `assess` ใน `index.html`

## ข้อจำกัดที่ควรรู้

- **ไม่ใช่ระดับน้ำจริงที่วัดได้:** ปริมาณน้ำในแม่น้ำมาจากโมเดล GloFAS ความละเอียดประมาณ 5 กม. และอาจเลือกแม่น้ำคลาดเคลื่อน ค่าที่แสดงเป็นอัตราส่วนเทียบช่วงที่ผ่านมา ไม่ใช่ระดับน้ำเป็นเมตร
- **จุดที่ไม่ใกล้แม่น้ำ** จะประเมินจากฝนเท่านั้น ซึ่งไม่ได้แปลว่าน้ำจะไม่ท่วม (เช่น น้ำเหนือหลาก น้ำขัง หรือระบบระบายน้ำไม่ทัน)
- **ช่วงเวลาเสี่ยงที่คาดเป็นเพียงการประมาณ:** คำนวณจากยอดฝนพยากรณ์และวันที่น้ำในแม่น้ำจำลองสูงสุด ไม่ได้รวมการระบายน้ำ น้ำเหนือ หรือสภาพพื้นที่จริง และเกณฑ์ (เช่น ฝน 6 ชม. ≥ 10 มม.) เป็นค่าตั้งต้น
- **สีบนแผนที่ไม่ใช่ขอบเขตน้ำท่วมจริง:** เป็นผลประเมินรายช่องตารางด้วยกฎเดียวกับการ์ดความเสี่ยง ช่องหนึ่งอาจกว้างหลายสิบกม. เมื่อซูมออก พื้นที่ไม่มีสีไม่ได้แปลว่าปลอดภัย และช่องที่เป็นทะเลก็ถูกประเมินจากฝนด้วย
- **ความสูงพื้นที่เป็นค่าโดยประมาณ** ความละเอียด ~90 ม. อาจคลาดเคลื่อนได้หลายเมตร และยังไม่ได้นำไปคำนวณความเสี่ยง
- **สถานที่ฉุกเฉินมาจาก OpenStreetMap** อาจไม่ครบหรือไม่เป็นปัจจุบัน และค้นเฉพาะตอนกดปุ่ม ไม่ใช่ศูนย์พักพิง หากฉุกเฉินให้โทร 1669 / 191 / 199
- ยังไม่ได้เชื่อมข้อมูลสถานีวัดระดับน้ำจริง (เช่น Thaiwater)
- แผนที่และข้อมูลต้องใช้อินเทอร์เน็ต ตอนออฟไลน์จะเห็นเฉพาะผลล่าสุดที่เก็บไว้
- แผนที่ใช้แผ่นภาพสาธารณะของ OpenStreetMap เหมาะกับการใช้งานเบาๆ

## แหล่งข้อมูล

- **ฝนและพยากรณ์:** [Open-Meteo](https://open-meteo.com) Weather Forecast API (CC BY 4.0, ฟรีสำหรับการใช้แบบไม่เชิงพาณิชย์)
- **ปริมาณน้ำในแม่น้ำ:** Open-Meteo Flood API จากโมเดล GloFAS / Copernicus Emergency Management Service
- **ความสูงพื้นที่:** Open-Meteo Elevation API จาก Copernicus DEM GLO-90
- **แผนที่และตำแหน่งสถานที่ฉุกเฉิน:** © OpenStreetMap contributors ผ่าน [Leaflet](https://leafletjs.com) และ Overpass API
- **ประกาศทางการ:** [Thaiwater](https://www.thaiwater.net) และ [กรมอุตุนิยมวิทยา](https://www.tmd.go.th)

## โครงสร้างไฟล์

```
index.html          โครงหน้าและ logic ของแอป
style.css           การตกแต่งทั้งหมด (สี ฟอนต์ เลย์เอาต์) แก้ที่นี่เพื่อปรับหน้าตา
sw.js               service worker (network-first, ใช้ข้อมูลที่เก็บไว้เมื่อออฟไลน์)
manifest.json       ข้อมูลสำหรับติดตั้งเป็นแอป
data/latest.json    (ไม่บังคับ) ข้อมูลสถานีวัดสำหรับเฟสถัดไป
```

`data/latest.json` ที่ตั้ง `"sample": true` จะถูกซ่อนไม่ให้ผู้ใช้เห็น หากใส่ข้อมูลสถานีจริงและตั้งเป็น `false` ช่อง "เลือกสถานีตรวจวัด" จะปรากฏขึ้นเอง

## ติดตั้งบน GitHub Pages

1. วางไฟล์ทั้งหมดไว้ที่รากของ repo โดยโฟลเดอร์ `data/` อยู่ข้างๆ `index.html`
2. เปิด **Settings → Pages** แล้วเลือก branch ที่ใช้เผยแพร่
3. รอ deploy ประมาณ 1–2 นาที แล้วเปิดลิงก์ของ Pages
